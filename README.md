# CryptoWatch

Persönliches Krypto- und Trading-Dashboard für Desktop und Smartphone.

## Vision

CryptoWatch beginnt als schlanker Kursticker und wächst später zu einem
persönlichen Trading-Dashboard.

## Erste Funktionen

- BTC
- ETH
- SOL
- XRP
- aktuelle Kurse
- 24h-Veränderung
- Favoriten
- Kursalarme
- verschiedene Börsen

## Spätere Funktionen

- Desktop-Banner
- Android-Widget
- iPhone-Widget
- Watchlists
- Portfolioübersicht
- Swing-Trading-Informationen
- technische Indikatoren

## Status

Ideenphase.

Die aktive Entwicklung beginnt erst nach der ersten veröffentlichbaren
Version von Easy PDF.
